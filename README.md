# Cricket Score Analyzer

This is a simple Cricket Score Analyzer project that I built using Python as part of my learning journey.

The project allows users to enter player statistics and analyze their performance through different metrics such as total runs, batting average, highest scorer, and more. The data can also be saved to a CSV file for future reference.

## Features

* Add player details and statistics
* Display all player records
* Calculate total runs and batting average
* Find the highest scorer
* Search for a player
* Save records to a CSV file
* Menu-driven interface

## Concepts Used

* Python Programming
* Object-Oriented Programming (OOP)
* Functions
* Lists
* CSV File Handling
* NumPy
* Git & GitHub

## Why I Built This Project

I built this project during my summer vacation to improve my Python programming skills and get hands-on experience with OOP, file handling, and basic data analysis.
